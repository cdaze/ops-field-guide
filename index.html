1 Models & agents — use the right tool

Matching the model or agent to the task is the single biggest performance gain available. Each has a distinct strength profile.

Models

Opus
Claude Opus
Deep reasoning · use when depth > speed
  • System architecture & design decisions
  • Multi-step reasoning chains
  • Complex code review & refactoring
  • Legal, financial & compliance synthesis
  • Ambiguous, open-ended analysis
Example
"Design a multi-site WAN topology for 6 warehouse locations with failover, segmented VLANs per function, and road-warrior VPN access."
Sonnet
Claude Sonnet
Everyday excellence · best all-round balance
  • Writing, editing, summarizing
  • Code generation & debugging
  • Research synthesis & reports
  • Most day-to-day ops tasks
  • Default model for agentic loops
Example
"Draft a carrier rate increase response email. Professional tone, firm but open to negotiation."
Haiku
Claude Haiku
Speed & volume · fast, cheap, high-throughput
  • Classification & tagging at scale
  • Routing logic in agentic pipelines
  • Short-form content generation
  • First-pass drafts before Opus review
  • Cost-sensitive API integrations
Example
"Classify each of these 300 support tickets as billing / carrier / WMS / general. Return JSON only."

Agents

Claude Code
Claude Code
Terminal-native · reads and writes real files
  • Build multi-file projects from a spec
  • Read, refactor, and commit codebases
  • Run bash, tests, install packages
  • Install & configure MCP servers
  • Manage git commits and PRs
Example
"Scaffold a Django scheduling app with Gmail SMTP. Create a CLAUDE.md with project conventions and push an initial commit."
Coworker
Coworker (beta)
Desktop automation · no code required
  • File & folder management on your desktop
  • Browser-driven form filling
  • Multi-app workflows without scripting
  • Repeated operations on local files
Example
"Rename all invoices in this folder to YYYY-MM-DD-Vendor format and move them to /Accounting/2026."
Claude in Chrome
Browser agent (beta)
See and act on any webpage
  • Web research & data extraction
  • Portal navigation & form filling
  • Price comparison across sites
  • Pulling live data into context
Example
"Open the carrier portal, pull all active loads from the last 7 days, and paste them into a summary table."
Claude Design
Claude Design (research preview)
Prompt → prototype · powered by Opus 4.7
  • Turn text prompts into interactive prototypes
  • Pitch decks, slides, UI mockups, one-pagers
  • Auto-builds a design system from your brand assets
  • Multiplayer — team edits in real time
  • Handoff to Claude Code for production build
Example
"Create an interactive dashboard mockup for our warehouse KPIs — inbound volume, dock utilization, and on-time shipping rate. Match our brand colors."
Access
Available to Claude Pro, Max, Team & Enterprise subscribers. Lives inside claude.ai — palette icon in the left sidebar. Not available on the free tier.

Decision flow

Complex architecture or deep analysis?→Opus
Build real files, scripts, or a codebase?→Claude Code
Prototype, mockup, deck, or visual?→Claude Design
Desktop tasks, no code needed?→Coworker
Writing, research, day-to-day ops?→Sonnet (default)
High volume, classification, routing?→Haiku

2 Skills, Claude Code & the Prompt API

Skills are reusable instruction bundles stored on disk. Claude Code reads them automatically before generating output — your standards follow every session without re-prompting.

Built-in skill library
Public skills — installed with Claude
Each skill is a SKILL.md with constraints, library choices, and examples for that output type.
  • docx — Word docs with TOC, headings, tables
  • pptx — slide decks, layouts, speaker notes
  • xlsx — spreadsheets, formulas, charts
  • pdf — create, merge, fill, OCR
  • frontend-design — React/HTML with design tokens
  • data-analysis — charts, statistical summaries
Claude Code — install & configure everything
One command, then describe what you need
npm install -g @anthropic-ai/claude-codebash
  • Install & configure MCP servers
  • Create CLAUDE.md project conventions
  • Scaffold Django / Next.js / FastAPI projects
  • Write, test, and commit automation scripts
Prompt API (PAI) — AI-powered artifacts
Artifacts can call the Anthropic API directly — Claude inside Claude. No backend, no deployment. Build interactive tools, dynamic reports, and live AI features embedded in any artifact.
Use case — ticket classifier
Paste support tickets → Haiku classifies → live table renders. No server needed.
Use case — model playground
Input box + model picker → compare Haiku / Sonnet / Opus side by side in one artifact.

3 Token strategy — do more with less

Every message burns tokens. These patterns help you manage complex tasks without blowing your context window or hitting rate limits.

Grant access, not content
MCP connectors — fetch exactly what's needed
Instead of pasting data into chat, connect Claude to the source.
  • Google Drive / Docs — search and read live
  • Gmail — read and draft without copy-paste
  • Calendar — check availability in context
  • GitHub — read, write, PR from chat
  • Obsidian — read/write vault notes directly
Only enable connectors when you need them. Each idle MCP adds ~200–400 tokens per message in tool-listing overhead.
Keep context lean
Context management patterns
  • Use Projects to persist instructions — not repeated pasted prompts
  • Break large tasks into chained conversations
  • Summarize completed steps before continuing
  • Ask Claude to output only what changed, not the full file
  • Use Haiku for routing; escalate to Sonnet only when needed
Pattern
"Summarize what we've built so far in 3 bullet points, then continue with the next section."
Agentic task decomposition
Structure complex tasks before starting. Give Claude a plan to execute, not a description to improvise.
Define outcome + constraints→ Break into numbered steps→ Assign model per step→ Review at checkpoints
Example — carrier audit pipeline
Step 1 (Haiku): classify each lane as active / inactive / disputed.
Step 2 (Sonnet): flag lanes with rate variance >12% vs market.
Step 3 (Opus): write the carrier negotiation recommendation memo.

4 TELOS — your Claude system prompt

TELOS is a structured prompt that tells Claude who you are, how you work, and what you need — so every conversation starts with full context rather than a blank slate.

Task · Environment · Language · Objectives · Style

Store it in 30-Library/Prompts/TELOS-System-Prompt.md and paste it into any Claude Project's system prompt field. Review quarterly or after major role/tool changes.

Choose your build method

Option A — PAI Installer
Automated interview
Paste the installer prompt into Claude Code or a PAI artifact. An automated interview runs and outputs your complete TELOS. Best for Claude Code users.
Option B — Recommended
Interactive interview
Start a fresh Claude chat, paste the interview prompt below. Claude guides you through in 5–10 minutes. Result is genuinely tailored to your operation.
Option C
Manual template
Edit the starter template in the scaffold. Fill in all [ ] placeholders. Fastest if you know exactly what you want from the start.

Option A — PAI installer prompt

You are a TELOS configuration assistant for operations and logistics professionals.
Interview the user to produce a complete TELOS system prompt for a Claude Project.

Rules: ask exactly one question at a time. Wait for each answer.
Do not generate the TELOS until all sections are complete.

Cover in order:
1. Role, title, and organization type (e.g. 3PL owner, IT director, ops manager)
2. Number of facilities and how they are organized
3. Key systems: WMS, TMS, ERP, IT/network tools, communication platforms
4. Primary Claude use cases (writing, analysis, automation, IT, all of the above)
5. Tone and format preference (concise vs. detailed, plain vs. technical)
6. Ambiguity handling — ask first, or attempt and flag uncertainty
7. Non-negotiables: things Claude should always or never do

Output the completed TELOS inside a markdown code block with clear T/E/L/O/S headers.prompt

Option B — Interview prompt

I want to build a TELOS system prompt to use across my Claude Projects.
I work in logistics / 3PL operations. Please interview me — one question at a time —
covering my role, tools, communication style, and working preferences.

After the interview, generate a complete TELOS with T / E / L / O / S sections
ready to paste into a Claude Project system prompt.prompt

Option C — Manual starter (3PL template)

**Task:** You are my operations and AI assistant for a third-party logistics company.

**Environment:**
- Organization: [Company name] — [number]-site 3PL warehouse operation
- Facilities: [naming convention, e.g. Site A through Site F]
- Key systems: [WMS platform], [TMS platform], [accounting/ERP]
- Team: [approximate headcount or team structure]
- Platforms: [Mac/Windows], [communication tools], [project tools]

**Language:**
- Direct and concise — skip preamble and pleasantries
- Plain language for business; precise and technical for IT/systems topics
- Markdown only when it genuinely adds clarity

**Objectives:**
- Manage day-to-day operations, carrier relationships, client communications
- Draft SOPs, emails, escalations, and operational reports
- Analyze operational data and surface actionable insights
- Support technology decisions across facilities

**Style:**
- If ambiguous, ask one clarifying question — do not guess
- When I ask for options, give 2–3 with a clear recommendation
- Flag when your training data may be outdated on fast-changing topicstemplate

5 Projects & artifacts

Projects give Claude persistent instructions and shared context. Artifacts are the outputs — rendered, downloadable, and reusable.

Projects — persistent workspace
A Project is a conversation space with a shared system prompt, uploaded docs, and memory that persists across chats.
  • Attach docs: runbooks, schemas, SOPs, rate sheets
  • Set system prompt once — applies to every chat in the project
  • Conversations are searchable via past chats
  • Good pattern: one project per facility, one per major initiative
Example project system prompt
"You are managing operations at Site B, a 250k sqft cross-dock facility. WMS: Extensiv. Refer to the attached rate card and SOP library."
Artifacts — rendered, reusable outputs
Artifacts render inline in chat — not just text.
  • Markdown — reports, runbooks, guides
  • HTML / React — dashboards, tools, forms
  • SVG — network diagrams, flowcharts
  • Code files — scripts, configs, ready to copy
Ask Claude to update the artifact rather than regenerating from scratch. Each edit preserves the structure and costs fewer tokens.
Artifact + PAI = live applications
Combine artifacts with the Prompt API to build tools that run Claude inside them.
Ticket classifier
Paste tickets → Haiku classifies → table renders live
Prompt playground
Input + model picker → compare Haiku/Sonnet/Opus
SOP generator
Fill a form → Sonnet writes the SOP → download as .md
To share any artifact: click the Share button (arrow icon) → generates a public URL anyone can open in their browser. No login required.

6 Pro tips

✏️ Be specific, not polite. "Write a Python script that reads a CSV of carrier IDs and hits our TMS API to pull active lanes, logging failures to a JSON file" beats "Can you help me with a script?"
🔢 Use numbered steps for complex tasks. "Step 1: … Step 2: … Step 3: …" forces Claude to execute in order and makes errors easier to catch at each stage.
🏷️ Request XML tags for structured output. "Return your answer in <analysis>, <recommendation>, and <code> tags" makes it easy to parse or route responses programmatically.
🚫 Give a negative example. "Write the summary. Do not use bullet points or the word 'leverage'." Negative constraints are more precise than style descriptions.
🧠 Ask for reasoning before the answer. "Think through this before answering" consistently improves accuracy on complex problems, especially with Sonnet.
🔄 Iterate, don't restart. "Update this to also handle…" keeps the context window loaded. New conversations cost setup tokens every time.
🔌 Disable unused MCP connectors. Each connected-but-idle MCP adds tool-listing overhead every turn. Toggle off what you're not using.
📄 CLAUDE.md is your project constitution. Put conventions, naming standards, and commit formats in a CLAUDE.md at the repo root. Claude Code reads it automatically every session.

Prompt cheatsheet

For better output
"Return only JSON — no preamble or backticks."
"Use <result> tags for your final answer."
"Be concise. Maximum 3 sentences."
"Explain your reasoning, then give the answer."
For complex tasks
"Before answering, list your assumptions."
"If uncertain, say so — don't guess."
"Show your plan first, then execute."
"Ask me one question if anything is unclear."

13 Claude MCP integration

Connects Claude directly to your vault. Requires Local REST API community plugin.

1
Set up Local REST APISettings → Community plugins → install Local REST API → open its settings → click Generate → note the port (default: 27123). Leave it running.
2
Open the Claude Desktop config file 
open -a TextEdit "~/Library/Application Support/Claude/claude_desktop_config.json"
# or in VS Code:
code ~/Library/Application\ Support/Claude/claude_desktop_config.jsonbash
notepad "$env:APPDATA\Claude\claude_desktop_config.json"
# or in VS Code:
code "$env:APPDATA\Claude\claude_desktop_config.json"powershell
If the file does not exist yet, create it — Claude Desktop picks it up on next launch.
3
Add the MCP server block 
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "obsidian-mcp-tools"],
      "env": {
        "OBSIDIAN_API_KEY": "your-api-key-here",
        "OBSIDIAN_HOST": "http://localhost:27123"

    }
  }
}json

15 Daily workflow

Capture → Process → Link

The most common failure with any knowledge system is friction at capture time. The fix: everything goes to Inbox first, no exceptions.

1. Capture
Anything into 00-Inbox. No tags, no folder decisions. Zero friction.
2. Process
Once per day: move items to the right folder, add frontmatter tags.
3. Link
Every new note links to at least one existing note via [[wikilinks]].

Daily note as operations log

  • Task list and priorities for the day
  • Decision log — what was decided and why
  • Record of Claude sessions: topic, model used, outcome
  • Input for memory and TELOS updates when something significant changes

Prompt library discipline

Every useful Claude prompt gets a note in 30-Library/Prompts/:
  • Exact prompt text — copy-paste ready
  • Model that gave the best result (Haiku / Sonnet / Opus)
  • Quality rating after real use (⭐ 1–5)
  • Notes on what variations improved output
  • Link added to Prompt-Index.md
